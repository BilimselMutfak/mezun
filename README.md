# Mezun Öğrenci Portalı

GitHub Pages üzerinde çalışabilecek basit, sunucusuz mezun öğrenci portalı.

## Dosyalar

- `index.html` → Ana sayfa
- `style.css` → Tasarım
- `script.js` → Arama, filtreleme, modal ve tema işlemleri
- `data.js` → Örnek mezun verileri

## GitHub Pages

1. Bu klasördeki dört dosyayı GitHub repository'nize yükleyin.
2. Repository → Settings → Pages bölümüne girin.
3. Source olarak `Deploy from a branch` seçin.
4. Branch olarak `main` ve klasör olarak `/root` seçin.
5. Save'e basın.
6. GitHub birkaç dakika içinde sitenizi yayınlar.

## Önemli

`data.js` içindeki bilgiler örnektir. Gerçek mezunların kişisel bilgilerini herkese açık bir JavaScript dosyasında tutmak yerine, gerçek kullanım aşamasında Firebase/Supabase gibi bir veritabanı ve uygun erişim kontrolleri kullanılmalıdır.
